## 💻 核心项目实战

### 🛡️ 金融风控 RAG 系统 (`finance-risk-rag-v2`)
**银行级多语言财务文本风控 AI 系统**
- **技术栈**：OCR (Tesseract 5.5) + BERT NER + RAG (Chroma + ONNX) + Kimi AI。
- **核心能力**：支持批量处理 PDF 财务文档，实现 95%+ 的 OCR 识别率。通过 12 类规则与 AI 增强实现 17 类金融实体抽取。
- **实战价值**：将贷前审查时间从 24 小时缩短至 10 分钟，大幅提升风控效率与预警准确率（提升 15%）。

### 🎥 批量换脸自动化工具 (`roop-cam-batch`)
**基于 Roop-Cam 的高效视频处理方案**
- **核心功能**：实现一键批量换脸，支持 GPU 加速（GTX 1660 Ti），完全脱离 GUI 界面，适合大规模自动化视频内容生产。
- **技术亮点**：集成了 InsightFace 与 ONNX Runtime，支持多视频并发处理，保持高画质与音频同步。

### 🔓 安全漏洞研究 (`pjcdb`)
**加密系统逻辑漏洞复现**
- **研究成果**：发现并复现了某加密系统在加密动作与进程启动之间的时间差漏洞。
- **核心原理**：通过监测工具发现加密动作存在滞后，通过在特定时间差内锁止加密动作并返回伪造的成功信号，实现“逻辑绕过”，使软件误认为加密已完成。

### 📊 企业级数据中台 
**数据中台项目**
- **架构设计**：构建五层数仓架构（ODS/DWD/DIM/DWS/DM），整合异构系统数据。
- **AI 增强**：开发了基于 RAG 的智能问答系统（kb_qa_mvp），支持多格式文档学习与深度财务归因分析。
- **模型实战经验**：
  - **Coze/微信集成**：在实战中发现，针对大陆特定业务场景，国产大模型在某些逻辑处理上仍有提升空间，而谷歌（Google）系列模型在复杂逻辑理解与跨语言支持上表现优异。
  - **OCR 与 Excel 解析**：实现了针对扫描件的深度 OCR 识别及 Excel Sheet 转 Markdown 的结构化解析。
